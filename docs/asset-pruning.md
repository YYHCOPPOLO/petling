# 基础功能资源清理 · 2026-10-20

根据当前运行源码、动画路由、点脸配置、基础物品目录及界面动态路径，对旧资源包做可达性审计，再删除未引用文件。本次不生成熊猫素材，不缩减商城品类、旧存档物品或现有随机动画的数量。

| --- | ---: | ---: | ---: |

| `resources/pet` 体积 | 329.3 MiB | 98.1 MiB | 231.2 MiB |
| 独立旧托盘图 `resources/icons/tray.png` | 1 | 0 | 1 |
| 动画目录 `Action` | 1,382 | 1,148 | 234 |
| 物品、课程、托盘等 `img_res` | 2,220 | 2,127 | 93 |

3,622 个删除文件来自已经归档的社区、旅行、相簿、邮件、签到、钓鱼、农场、密室及小游戏目录。其余删除内容包括未路由的 `prostrate` 动作、旧动作副本、未使用的互动/停止片段、Flash 编辑源文件、旧 ICO 托盘版本、闲置界面切片和扩展入口图标。

保留资源对应 2,472 个逻辑 URL，以及 1,201 个自动选取的高清副本。检查程序枚举完整随机动作范围，保留 664 个当前可路由的 `play` 片段。食品、清洁用品等旧存档可持有的物品仍保留图像；仅删除目前不需要的资源不会把全部历史商品收敛到当前在售的 138 种。

`scripts/asset-dependencies.ts` 记录依赖生成规则；`npm run assets:audit` 输出 `.verification/assets/dependencies.json`，列出每个逻辑 URL 的来源和未引用文件。构建遇到缺失依赖或遗留未引用资源时会失败。SWF 的字面量引用扫描与桌面回归配合使用，不作为任意动态脚本依赖的完整证明。

发行构建会重建 `out/asset-pack`，仅复制实际选中的资源、高清副本和资源包配置；Electron Builder 从该目录取资源。预览文件和生成草稿放在 `resources/` 之外。被删除资源仍存在于 Git 历史中，工作树清理不重写仓库历史。

本次保留的素材继续沿用原版权声明，后续再按逻辑功能制作原创熊猫资源。验证结果见 [验证记录](verification.md)。
