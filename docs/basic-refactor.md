归档源码位于 `archive/legacy-gameplay/`，不在 TypeScript、Vite 或 Electron 打包入口中。原始宠物素材继续保留在 `resources/pet/`，本次不删除美术文件，因此素材体积没有相应缩小。

## 实现边界

`src/core/pet/` 不依赖 DOM、Electron、SWF 或模型请求。物品使用、整车购买、治疗、互动、学习打工及考试返回明确的 `succeeded + data + patch` 或 `failed + error`，不直接修改传入状态。

`src/renderer/pet/commands.ts` 统一发布业务结果。`store.publishChange` 先安装整组修改，再通知背包、资料和动画，避免界面读到已扣钱但尚未入包的中间状态。喂食、清洁、治疗和学习打工不再由动画回调扣库存或启动；动画失败或被抢占不会撤销已经提交的效果。

购物车先校验全部商品，再一起扣费入库。数量、余额、会员、等级、物品不足及活动冲突都由业务模块检查。升学时重新检查课程进度和原题库答案，重复提交不能重复升学。停止活动会清空进度，完成活动会同时清除活动标记和发放奖励，重复 tick 不会再奖励。

本次仍使用现有游戏存档及渲染层成长时钟。业务命令通过唯一的渲染层适配器同步提交，再由现有主进程仓库原子落盘。完整的主进程业务状态托管、持久化请求去重和外部可写工具入口属于评估文档的后续工作，本次没有开放这些接口。

## 存档兼容

- 保留旧字段、农场等扩展数据和未知物品；本版本不加载相应模块、不推进扩展活动、不发放相关奖励。
- 旧存档中的进行中旅行转存到 `saveJsonData.legacyTrip`，清除活动占位，避免阻塞基础学习打工。
- 旧学习打工按游戏时钟恢复；暂停成长或死亡期间不按离线时长完成活动。
- 新存档不再创建邮件、签到、今日任务、池塘或农场记录。
- 导出保留兼容数据，默认清空 `settings.aiKey`；本地配置不变。凭据改为主进程独立存储留在后续接入阶段。

## 验证

`npm test` 覆盖既有桌面/存档/资源规则及新增基础业务边界。`npm run build` 执行基础关键资源检查、类型检查和生产构建。`npm run test:desktop` 使用隔离临时存档运行真实 Electron，验证保留入口及移除扩展入口，产出截图和进程清理报告。

当前验证结果与平台限制见 [验证记录](verification.md)。真实文档阅读、知识检索、持久化会话/任务、MCP 及 harness 尚未实施，不作为这一步的验收内容。
