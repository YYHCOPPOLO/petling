# M0 第二批：身份、记忆与可恢复的聊天任务

2026-10-22 实施。在第一批养成状态宿主上继续完成独立持久化和任务生命周期，当前执行器仍是文本聊天；没有把文本回复当作工具执行或外部 Agent 接续。

## 使用入口

右键或托盘选择「和我聊天」，面板提供「对话」「任务」「记忆」「性格」。选择明确的对话继续聊天，也可新建或删除对话。宠物未领养、死亡或埋葬时仍保留此入口。关闭面板、隐藏宠物和暂停成长不会取消正在进行的回复。

性格配置包含固定伙伴 ID、表达偏好及用户称呼。首次创建时继承现有宠物存档中的用户称呼；之后独立保存，更换模型不改变身份。宠物名字继续通过宠物资料修改。当前新性格应用于展开面板中的聊天，原有待机短句改写尚未迁入该协议。

记忆由用户主动创建，区分个人偏好、共同经历和项目资料，支持来源、项目标识、中文子串搜索、修改和遗忘。不会自动把全部聊天沉淀为个人偏好。聊天使用最近最多 20 条个人偏好/共同经历，合计正文及来源不超过 12,000 字符；项目资料不自动送入无项目范围的聊天。此前成功对话最多带入 12 条消息、24,000 字符；单次用户输入最多 8,000 字符，返回文本最多保存 32,000 字符。

## 存储与事务

`companion.sqlite` 位于应用用户数据目录，独立于 `save.json`。使用当前 Electron 自带的 `node:sqlite`，不增加运行依赖或原生模块。数据库仅在首次使用伙伴功能时启动专用 worker，主进程通过有限队列访问；没有在渲染层暴露文件路径、SQL 或任意方法调用。一个应用最多一个数据库 worker，最多 64 个待处理数据库请求；目前打开后保留到退出，空闲回收和性能测量仍待后续实现。

schema v1 管理身份、记忆、对话、消息、任务及事件，开启 WAL、FULL 同步和外键。`user_version` 控制初始化，拒绝比当前实现更新的 schema，不覆盖损坏数据库。任务创建、用户消息和排队事件同事务提交；回复、成功状态和完成事件同事务提交。网络调用期间不持有数据库事务。

每个聊天请求使用 UUID，绑定对话 ID 和输入指纹。回执丢失可重试相同 ID；重复请求返回已有任务，不再次生成消息。同一 ID 不同输入被拒绝。任务保存根任务、父任务、来源、后端和应用会话 ID；本批都是根聊天任务，尚无外部厂商原生会话 ID，也不猜测「最近会话」。凭据只在执行时读取原有设置，不复制到任务或记忆数据库；原有 `settings.aiKey` 的主进程独立凭据迁移仍未完成。

## 取消、退出与恢复

协议包含 queued、running、waiting_input、waiting_approval、interrupted、succeeded、failed、cancelled。本批文本执行器实际产生排队、执行、中断、成功、失败、取消；等待输入/授权预留给后续工具执行器。

同时执行一条回复，最多八条运行或排队。取消先持久化取消状态并改变 attempt，再中止本任务拥有的请求；后端迟到结果无法提交。失败或中断后可显式「继续」，重新请求同一配置的文本模型。更改模型配置时拒绝重试原任务，用户可以在同一对话发新消息。这里没有任何文件修改、提醒创建或其他外部副作用，不能将该重试策略直接套到这些能力上。

退出时中止请求、事务保存中断状态、关闭数据库并终止 worker。突然退出后的首次数据库加载将遗留活动任务标为中断，不自动重发、不按离线时长推断完成。事件记录包括状态、执行轮次和时间；恢复保留原任务和对话 ID，不重复插入用户消息。

## 遗忘与数据保留

记忆修改和删除有 revision 校验；删除保留无正文的 ID 墓碑，迟到的旧编辑不能重建记忆。性格或记忆变更会更新上下文版本并中断现有回复，旧请求不能写回。历史聊天仍可查看，但旧版本的对话不再带入新请求，避免遗忘内容从此前回答中再次被召回。

删除对话会取消其任务，移除消息、执行事件和任务正文；只保留阻止迟到创建请求的无正文标识及指纹。单独保存的记忆仍保留，可在记忆页遗忘。删除不会撤回已经发送到模型服务的内容，也不删除用户已有的备份。

宠物重生和导入只影响兼容宠物存档，身份、记忆和历史对话保留；进行中的回复保存为中断。现有宠物 JSON 导出不包含伙伴数据库，界面已明确说明。本批尚未提供伙伴数据库的备份/恢复入口，不能将宠物存档导出视为全部数据备份。

## 验证与下一步

测试覆盖事务失败、跨重启去重、明确会话恢复、attempt 隔离、取消、遗忘、旧历史召回隔离、中文搜索、队列上限和输入验证。Electron 回归使用真实 worker/preload/SQLite，验证面板操作、后台回复、取消、退出中断和重启保留；实际结果见 [验证记录](verification.md)。

后续仍需凭据迁移、备份恢复、长列表完整分页、自己的工具循环、任务产物与检查点、外部后端探针、通知策略及性能基线。当前列表返回最近 100 条，聊天历史按每页 100 条加载、面板最多同时显示 500 条；数据库中的其他历史不会自动删除。本批不是完整 M0，也不是 R02/R07/R08 的外部工作任务验收。

实现依据：[Node.js SQLite](https://nodejs.org/docs/latest-v24.x/api/sqlite.html)。实际应用打包运行的 Node.js 为 24.21.0，开发机 Node.js 为 23.11.0。
